# Кемпинг «У озера» — учебное бронирование

**Автор:** Терехов Артём, группа 2-МД-20
**Практика 5 · Интерактивная карта и сервис бронирования**

## Тема
Сайт бронирования мест в кемпинге. Пользователь выбирает место на схеме
(палатка, автодом, глэмпинг), указывает число гостей и суток, видит итоговую
стоимость и оформляет учебную бронь. Свои брони можно отменить.

## Запуск
Проект использует ES-модули, поэтому запускается через HTTP-сервер, а не
двойным щелчком по HTML. 
- VS Code + расширение **Live Server**: правый клик по `index.html` →
  «Open with Live Server».
- Либо из папки проекта: `python -m http.server 5500`, затем открыть
  `http://localhost:5500`.

Файлы лежат в одной папке: `index.html`, `style.css`, `data.js`, `storage.js`,
`main.js`.

## Функции
- Схема кемпинга и список мест строятся из одного массива `PLACES`
  (8 мест, 2 изначально заняты) с уникальными `id`.
- Состояния «Свободно / Выбрано / Занято» обозначены текстом, иконкой и
  оформлением, а не только цветом. Занятое место выбрать нельзя.
- Два фильтра: минимальная вместимость и максимальный тариф. Список и схема
  показывают одинаковый результат.
- Выбор места на схеме и в списке синхронизирован; выбор работает с клавиатуры.
- Карточка места с формой: гости (1 — вместимость) и сутки (1–30).
  Итог = тариф за сутки × число суток, пересчитывается при вводе.
- Подтверждение создаёт одну запись; неверные значения показывают ошибку,
  бронь не создаётся. Повторная проверка занятости перед записью исключает дубли.
- «Мои брони»: сохранение в `localStorage`, восстановление после перезагрузки,
  отмена освобождает место в списке и на схеме, кнопка сброса своих броней.
- Повреждённые данные в `localStorage` и запрет сохранения показывают понятное
  сообщение, страница продолжает работать.
- Адаптивная вёрстка (проверено на 360, 768, 1280 px), видимый фокус,
  подписи полей, `aria-pressed` у кнопок выбора.

## Ограничение учебного бронирования
Это учебное демо. Реальная бронь и оплата не выполняются, сервер и регистрация
не используются. Бронирования сохраняются только в localStorage текущего
браузера и пропадут при очистке данных браузера или на другом устройстве.
На странице выведена подпись: «Учебное демо: бронирования сохраняются только
в этом браузере».

## Источники изображений
Внешние изображения не используются. Схема кемпинга (озеро, лес, дорожка,
костёр, солнце) нарисована средствами CSS, иконки мест — эмодзи ⛺ 🚐 🏕.
Шрифты Fraunces и Inter подключены через Google Fonts.

## Полезные промпты и результат
1. **Основа.** «Создай сайт бронирования мест в кемпинге на HTML/CSS/ванильном
   JS: схема с озером и лесом, 8 мест разных типов, 2 заняты, фильтры по
   вместимости и тарифу, форма гостей и суток, итог = тариф × сутки,
   подтверждение и отмена, зелёно-песочное оформление».
   Результат: рабочий каркас страницы, массив `PLACES`, схема и список из одних
   данных.
2. **Сохранение и ошибки.** «Добавь сохранение броней в localStorage с
   проверкой структуры: известные id, допустимые числа, без повторов, без
   броней исходно занятых мест; при повреждённых данных покажи сообщение и не
   ломай страницу».
   Результат: `storage.js` с валидацией, отдельный ключ приложения
   `camping-bookings-v1` и понятные сообщения об ошибках.
3. **Защита от дублей.** «Проверь перед записью, что место всё ещё свободно,
   и не создавай повторную бронь при двойном нажатии».
   Результат: повторная проверка `occupiedIds()` в обработчике формы и снятие
   выбора после подтверждения.
